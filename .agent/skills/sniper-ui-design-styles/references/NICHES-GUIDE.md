# Guia de Estilos por Nicho e Indústria

Este documento fornece recomendações detalhadas de estilos visuais para diferentes nichos, indústrias e tipos de página.

---

## POR TIPO DE PÁGINA

### Landing Pages de Conversão

**Objetivo**: Maximizar conversões (leads, vendas, signups)

**Estilos Primários**:
1. **Minimalismo** - Remove distrações, foca no CTA
2. **Single Column** - Narrativa linear guiada
3. **High Contrast** - CTAs impossíveis de ignorar

**Configuração Recomendada**:
- Hero com proposta de valor clara
- Uma cor de acento para todos os CTAs
- Máximo 3-4 seções
- Social proof visível
- Sem navegação complexa

**Evitar**:
- Muitos estilos visuais competindo
- Animações que distraem do CTA
- Múltiplas cores de botão

---

### Landing Pages de Produto SaaS

**Objetivo**: Demonstrar valor, gerar trials/demos

**Estilos Primários**:
1. **Bento UI** - Showcase de features
2. **Dark Mode** - Aparência tech/inovadora
3. **Aurora UI** - Premium e sofisticado

**Configuração Recomendada**:
- Hero com screenshot/demo do produto
- Bento grid para features
- Social proof (logos, testimonials)
- Pricing transparente
- CTA trial/demo

**Exemplos de Estrutura**:
```
Hero (proposta de valor + demo visual)
↓
Logos de clientes (social proof)
↓
Bento Grid de features (3-6 items)
↓
Feature destaque (full-width)
↓
Testimonials
↓
Pricing
↓
FAQ
↓
CTA final
```

---

### Landing Pages de Infoprodutos (Mercado BR)

**Objetivo**: Venda direta, alta conversão

**Estilos Primários**:
1. **Single Column** - Narrativa de vendas
2. **Neo-Brutalism** - Urgência e destaque
3. **High Contrast** - CTAs chamativos

**Configuração Recomendada**:
- Headline forte com benefício principal
- Vídeo de vendas (VSL) no topo
- Bullets de benefícios
- Bônus em cards destacados
- Garantia com selo visual
- Depoimentos em vídeo
- FAQ
- Múltiplos CTAs ao longo da página

**Cores que Funcionam**:
- Vermelho/Laranja para urgência
- Verde para dinheiro/resultado
- Azul para confiança
- Amarelo para destaques

---

### Sites Institucionais / Corporativos

**Objetivo**: Credibilidade, informação

**Estilos Primários**:
1. **Minimalismo** - Profissional e limpo
2. **Line Art** - Sofisticado e B2B
3. **Material Design** - Padrão reconhecível

**Configuração Recomendada**:
- Navegação clara e completa
- Hero com missão/proposta
- Sobre a empresa
- Serviços/Produtos
- Cases/Portfolio
- Equipe (opcional)
- Contato

---

### E-commerce / Loja Virtual

**Objetivo**: Vendas, navegação de produtos

**Estilos Primários**:
1. **Card-based UI** - Grid de produtos
2. **Flat Design** - Performance e clareza
3. **Minimalismo** - Foco nos produtos

**Configuração Recomendada**:
- Busca proeminente
- Categorias claras
- Grid de produtos consistente
- Filtros funcionais
- Checkout simplificado

**Evitar**:
- Estilos que distraem dos produtos
- Animações pesadas (performance)
- Dark mode em produtos físicos (distorce cores)

---

### Portfólio Pessoal / Criativo

**Objetivo**: Impressionar, mostrar trabalho

**Estilos Primários**:
1. **Brutalism** - Diferenciação
2. **Oversized Typography** - Statement
3. **Asymmetric Grid** - Criatividade

**Configuração Recomendada**:
- Hero impactante com nome/título
- Grid de projetos
- Sobre + foto
- Contato

**Dica**: Escolha um estilo que reflita seu trabalho. Designer minimalista = site minimalista.

---

### Blog / Publicação

**Objetivo**: Leitura, engajamento com conteúdo

**Estilos Primários**:
1. **Editorial** - Magazine feel
2. **Minimalismo** - Foco no texto
3. **Typography Driven** - Elegância

**Configuração Recomendada**:
- Largura de leitura confortável (65-75ch)
- Tipografia legível (16px+ corpo)
- Categorias/tags
- Posts relacionados
- Compartilhamento social

---

### Dashboard / App

**Objetivo**: Funcionalidade, usabilidade

**Estilos Primários**:
1. **Flat Design** - Performance
2. **Neumorphism** - Apps de controle
3. **Dark Mode** - Uso prolongado

**Configuração Recomendada**:
- Sidebar ou topbar navegação
- Cards para métricas
- Data visualization clara
- Estados de loading
- Feedback visual em ações

## POR PÚBLICO-ALVO

### Gen Z (nascidos 1997-2012)

**Estilos que Ressoam**:
- Neo-Brutalism
- Anti-Design
- Y2K Revival
- Neon/Glow
- Vaporwave

**Características**:
- Autenticidade > perfeição
- Memes e humor
- Mobile-first obrigatório
- Vídeo curto
- Social integration

---

### Millennials (nascidos 1981-1996)

**Estilos que Ressoam**:
- Minimalismo
- Aurora UI
- Glassmorphism
- Retro (90s nostalgia)

**Características**:
- Clean e funcional
- Valores (sustentabilidade, etc.)
- Reviews e social proof
- Conveniência

---

### Gen X (nascidos 1965-1980)

**Estilos que Ressoam**:
- Material Design
- Flat Design
- Minimalismo
- Corporate clean

**Características**:
- Funcionalidade primeiro
- Informação clara
- Sem "fluff"
- Credibilidade

---

### Baby Boomers (nascidos 1946-1964)

**Estilos que Ressoam**:
- Alto contraste
- Tipografia grande
- Layout tradicional
- Material Design

**Características**:
- Legibilidade máxima
- Navegação óbvia
- Telefone de contato visível
- Sem assumptions técnicas

## COMBINAÇÕES DE ESTILOS

### Tech Premium
```
Base: Dark Mode
+ Aurora UI (background)
+ Glassmorphism (cards)
+ Bento UI (features)
```

### Startup Friendly
```
Base: Minimalismo
+ Gradient backgrounds
+ Hand-drawn illustrations
+ Neo-Brutalism (CTAs)
```

### Corporate Moderno
```
Base: Flat Design
+ Line Art (ícones)
+ Card-based (sections)
+ Scroll animations (sutil)
```

### Creative Agency
```
Base: Asymmetric Grid
+ Oversized Typography
+ Cursor Interactions
+ Kinetic elements
```

### Wellness App
```
Base: Organic/Blob
+ Pastel colors
+ Neumorphism (controles)
+ Microinteractions suaves
```
